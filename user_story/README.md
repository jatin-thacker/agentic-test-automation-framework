# User Story Inputs

This folder contains SauceDemo user stories in `.story.md` format so they can be used directly with:

```bash
npm run agent:generate -- --story user_story/<file>.story.md
```

Recommended start files:
- `verified-saucedemo-user-stories.story.md` (all stories in one file)
- `us001-login-valid-and-invalid-credentials.story.md` (single focused story)
