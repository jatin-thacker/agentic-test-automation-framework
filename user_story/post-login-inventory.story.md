User Story: Inventory experience after successful login

As an authenticated user,
I want to land on the inventory page after login,
So that I can view available products and continue shopping.

Acceptance Criteria:
- Given the user is on the login page
- When the user logs in with valid credentials
- Then the user should be navigated to the inventory page
- And the inventory container should be visible
- And product items should be displayed for browsing
