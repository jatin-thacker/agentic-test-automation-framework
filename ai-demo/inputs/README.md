# AI Demo Inputs

Future AI-assisted runs can start from several input types:

1. Plain-English test objective.
2. User story from `user_story/`.
3. URL or application path.
4. Existing manual test case.
5. Existing failed test output.

For this MVP, JIRA integration is out of scope. Copy relevant story or ticket details into one of the templates in this folder before starting a generation run.
