# AI Demo Evidence

This folder stores evidence from AI-assisted demo runs.

Agent instructions, reusable prompts, and framework rules live in:

- `AGENTS.md`
- `.github/copilot-instructions.md`
- `.github/instructions/`
- `.github/prompts/`
- `.github/agents/`

Do not use this folder as a competing instruction source.

Generated run evidence should be written under:

- `ai-demo/runs/<timestamp>/`
