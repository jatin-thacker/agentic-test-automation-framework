# Demo Positioning

Preferred framing:

```text
AI-assisted Playwright automation accelerator built on top of an existing enterprise-style QA framework.
```

Avoid claiming:

```text
Fully autonomous AI test engineer.
```

## Demo Narrative

The framework can be demonstrated as:

```text
Requirement/story -> AI-assisted test design -> UI exploration -> framework-compatible automation -> execution -> failure analysis -> report.
```

The value is controlled acceleration: the AI assistant reads the framework context, follows project rules, proposes or edits normal framework files, runs available commands, analyzes failures, fixes high-confidence generated-code issues, and leaves a reviewable evidence trail.
